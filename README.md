# 🚆 Smart RailWay - Train Reservation System

A complete web-based train ticketing and reservation system. It provides a seamless experience for travelers to book trips and a comprehensive dashboard for administrators to manage operations.

## ✨ Features

### 👤 User Panel
* **Authentication:** Secure sign-up and log-in.
* **Search Trips:** Filter available train trips by departure and arrival stations.
* **Booking System:** Book tickets with automatic seat availability updates.
* **Active Bookings:** View upcoming trips and generate **QR Codes** for tickets.
* **Booking History:** Access past trips and tickets.
* **Profile Management:** Update personal information.

### 🛠️ Admin Dashboard
* **Live Statistics:** Track total users, active trips, active tickets, and revenue (Daily/Weekly/Monthly).
* **Trip Management:** Add new trips, edit details, or delete them.
* **Train Management:** Monitor train status and toggle maintenance modes.
* **Customer Management:** View user tickets and reclaim seats by canceling tickets if needed.

## 💻 Tech Stack
* **Frontend:** HTML5, CSS3, Vanilla JavaScript
* **Backend & Database:** [Supabase](https://supabase.com/) (PostgreSQL & Authentication)
* **Libraries:** QRCode.js, Boxicons, FontAwesome

## 🚀 How to Run
1. Clone or download this repository.
2. Open the project folder in your code editor (e.g., VS Code).
3. Open `index.html` in your browser (Using the **Live Server** extension is recommended).
4. You can switch between 'User' and 'Admin' login from the `sign-in.html` page.
